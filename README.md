# Pixion Scoop bucket

```powershell
scoop bucket add pixionco https://github.com/pixionco/scoop-bucket
scoop install pixionco/lumin-cli
scoop update lumin-cli
```

| Manifest | Command | Source |
|---|---|---|
| `lumin-cli` | `lumin` | [pixionco/lumin](https://github.com/pixionco/lumin) releases |

Manifests are updated automatically by each release; don't edit them by hand.
Report problems at [pixionco/lumin issues](https://github.com/pixionco/lumin/issues).
